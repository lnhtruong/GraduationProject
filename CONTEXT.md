# Highlight Generation

Video highlight reels are generated by an OpenAI/local-LLM pipeline (run in a Colab-hosted FastAPI worker, `Highlight_Final.ipynb`) that selects a subset of a video's subtitle content. This section of the glossary covers the vocabulary introduced by the **keep/remove segment selection** capability, which lets a user constrain which subtitle content the pipeline is allowed to use.

## Language

**SRT Index**:
The 1-based block number of a subtitle entry as it appears in the video's SRT file (matches `srt_to_segments()` output). The unit used to identify a Segment for keep/remove selection — not a timestamp.
_Avoid_: subtitle line number, timestamp

**Keep Segment**:
A contiguous range of SRT Indices (`{start_index, end_index}`) that the user requires to appear in the final highlight output, regardless of what the LLM would have chosen on its own. Enforced by Force-Include.
_Avoid_: pinned segment, required segment

**Remove Segment**:
A contiguous range of SRT Indices that the user requires to be entirely absent from the final highlight output. Enforced by Hard-Filter — removed before the LLM ever sees the content.
_Avoid_: excluded segment, blocked segment (the code already uses "blocked_indices" for a related-but-distinct internal LLM-anchor concept — don't conflate the two)

**Hard-Filter**:
Deleting Remove Segments from the parsed segment list immediately after SRT parsing, before any grouping, prefiltering, or LLM call. Guarantees the LLM never receives the removed content, as distinct from merely instructing it to avoid picking that content.

**Force-Include**:
Unioning Keep Segments into the LLM's selected output indices *after* the LLM has made its selection, guaranteeing their presence in the final result independent of whether the LLM chose them. The Keep Segments are also described in the prompt so the LLM can build coherent surrounding narrative around them — Force-Include is the backstop, not the sole mechanism.

**Precondition Video**:
A video whose `videos.srt_raw_url` column is already populated (an SRT was previously generated/attached). Keep/Remove Segment selection is only usable against a Precondition Video — checked via a new synchronous `inference_service → media_service` lookup, gated on the client supplying `video_id`.
