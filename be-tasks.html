BE-01 [M1] Migration: Tạo bảng DiscussionPosts & DiscussionUpvotes M1 · Forum

Mô tả

Tính năng Discussion Forum chưa được implement. Task này tạo 2 file migration mới để dựng schema từ đầu cho hệ thống Q&A theo lesson.

File 1 — 036_discussion_posts.js: Tạo bảng DiscussionPosts với các cột:

  • id INT PK AUTO_INCREMENT
  • lesson_id INT NOT NULL — FK → Lessons.id
  • user_id INT NOT NULL — FK → Users.id
  • parent_id INT NULL — self-ref FK → DiscussionPosts.id (dùng cho reply)
  • content TEXT NOT NULL
  • is_best_answer BOOLEAN DEFAULT FALSE
  • upvotes INT DEFAULT 0

  • id INT PK AUTO_INCREMENT
  • post_id INT NOT NULL — FK → DiscussionPosts.id
  • user_id INT NOT NULL — FK → Users.id
  • Unique constraint: (post_id, user_id) — tránh upvote trùng.
Tiêu chí nghiệm thu
  • knex migrate:latest chạy thành công cả 2 file, không lỗi.
  • knex migrate:rollback drop đúng 2 bảng, không ảnh hưởng bảng khác.
  • Schema sau migration khớp đặc tả: đúng kiểu dữ liệu, FK hợp lệ, index tồn tại.

Mô tả
  • Upvote toggle: POST /api/discussions/:postId/upvote. Tạo bảng DiscussionUpvotes (user_id, post_id) với unique constraint. Bấm lần đầu = insert + tăng upvotes counter. Bấm lần hai = delete + giảm counter. Trả về { upvotes, voted: boolean }.

BE-09 [M2] Filter & Sort: Lọc theo category, level, giá, rating + sắp xếp M2 · Search

Mô tả

  • Filter params:
    • categoryId[] — multi-value, VD: ?categoryId=1&categoryId=3 → OR condition.
    • level — Beginner | Intermediate | Advanced.
    • minPrice / maxPrice — range giá (số dương). minPrice=0&maxPrice=0 = free courses.
    • minRating — float từ 0–5, lọc theo avgRating >= minRating.

    • newest — createdAt DESC (default).
    • popular — enrollCount DESC.
    • rating — avgRating DESC.
    • price_asc / price_desc — theo giá.
  • Có thể kết hợp q + bất kỳ filter nào.
  • Thêm endpoint /api/categories (GET, public) trả về [{ id, name, courseCount }] để FE populate filter panel.
Tiêu chí nghiệm thu
  • Filter level=Beginner&minPrice=0&maxPrice=500000 trả về đúng tập kết quả, không có khóa ngoài điều kiện.
  • Filter categoryId=1&categoryId=3 trả về khóa thuộc category 1 HOẶC 3.
  • Sort popular → item đầu tiên có enrollCount cao nhất.
  • Kết hợp q=react&level=Intermediate&sort=rating hoạt động đúng.
  • /api/categories trả về courseCount là số khóa publish của category đó (không tính draft).
Ghi chú kỹ thuật:
  • Build WHERE clause động trong Sequelize với Op.and, Op.or, Op.between.
  • minRating filter cần HAVING clause (aggregate), không phải WHERE.
  • Validate minPrice, maxPrice là số không âm. minPrice > maxPrice → 400.

BE-10 [S3] Revenue Summary & Time-series API cho Instructor S3 · Revenue
🗃 Service: course_service (hoặc payment_service) ⏱ Estimate: 1.5 ngày
Mô tả

Xây dựng API doanh thu dành riêng cho instructor, join bảng Transaction_Items + Transactions + Courses. Chỉ tính transaction status = 'paid'. Instructor chỉ thấy dữ liệu của khóa học do mình tạo.

  • GET /api/instructor/revenue/summary — trả về: { allTime, thisMonth, lastMonth, growthPercent }. Growth = (thisMonth - lastMonth) / lastMonth * 100 (handle chia cho 0).
  • GET /api/instructor/revenue/timeseries — params: from, to (ISO date string), granularity=daily|weekly|monthly. Trả về array [{ date, revenue, enrollCount }]. Date format: YYYY-MM-DD (daily), YYYY-[W]WW (weekly), YYYY-MM (monthly). Các ngày/tuần/tháng không có giao dịch → trả về revenue: 0, enrollCount: 0 (không skip).
  • Default range nếu không truyền from/to: 30 ngày gần nhất.
Tiêu chí nghiệm thu
  • Instructor A không thấy doanh thu của Instructor B (strict isolation).
  • Summary allTime = sum của toàn bộ Transaction_Items.price đã paid.
  • Time-series granularity=monthly&from=2026-01-01&to=2026-12-31 → trả về đủ 12 phần tử kể cả tháng 0 đồng.
  • growthPercent = null khi lastMonth = 0 (tránh Infinity).
  • Params from > to → 400 Bad Request.
Ghi chú kỹ thuật:
  • Query join: Transaction_Items → Transactions (status=paid) → Courses (user_id = instructorId).
  • Dùng MySQL DATE_FORMAT để group theo granularity. VD: DATE_FORMAT(paid_at, '%Y-%m') cho monthly.
  • Generate date series đầy đủ ở application layer (JS) sau khi query, fill 0 cho ngày trống.
  • Module tạo tại course_service/src/instructor-revenue/ hoặc expose qua course.service.ts.
