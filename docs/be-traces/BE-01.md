## Schema details

### `discussion_posts`
| Column | Type | Notes |
|---|---|---|
| `id` | INT UNSIGNED AI PK | |
| `lesson_id` | INT NOT NULL | FK → `lessons.id` ON DELETE CASCADE |
| `user_id` | INT NOT NULL | FK → `users.id` ON DELETE CASCADE |
| `parent_id` | INT UNSIGNED NULL | self-FK → `discussion_posts.id` ON DELETE CASCADE (replies) |
| `content` | TEXT NOT NULL | |
| `is_best_answer` | TINYINT(1) DEFAULT 0 | flagged by instructor in BE-03 |
| `upvotes` | INT DEFAULT 0 | denormalised counter, maintained by BE-03 |
| `created_at` / `updated_at` | DATETIME | auto |

Indexes:
- `idx_discussion_posts_lesson_created (lesson_id, created_at)` — list per lesson newest-first
- `idx_discussion_posts_parent (parent_id)` — fast reply lookup
- `idx_discussion_posts_user (user_id)` — author filter

### `discussion_upvotes`
| Column | Type | Notes |
|---|---|---|
| `id` | INT UNSIGNED AI PK | |
| `post_id` | INT UNSIGNED NOT NULL | FK → `discussion_posts.id` ON DELETE CASCADE |
| `user_id` | INT NOT NULL | FK → `users.id` ON DELETE CASCADE |
| `created_at` | DATETIME | |

Unique: `uniq_discussion_upvotes_post_user (post_id, user_id)` — prevents duplicate upvotes.

## Verification performed

- knex migrate:latest applied both files successfully.
- knex migrate:rollback x2 dropped both tables without touching users/lessons.
- Re-applied — schema identical (idempotent hasTable guard).
- Insert a parent post + reply (with parent_id) + upvote — all succeeded.
- Duplicate (post_id, user_id) insert rejected with ER_DUP_ENTRY — unique constraint enforced.

## Design notes

- Signed vs unsigned: users.id and lessons.id are signed INT in the existing schema, but knex increments() produces UNSIGNED. FK type-compatibility chosen accordingly: lesson_id/user_id signed; parent_id and post_id unsigned.
- Naming: snake_case plurals to match all existing tables (courses, lessons, feedbacks, …). Jira card uses PascalCase logical names; the actual MySQL tables are snake_case.
- CASCADE deletes on parent_id cascade replies when the parent post is removed.
